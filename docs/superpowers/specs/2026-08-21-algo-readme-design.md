# Algo README 设计说明

## 目标

为团队内部开发者编写一份中文为主的项目 README，使新成员能够快速理解 EEG 运动想象算法的职责、数据流、目录结构、运行入口、测试方式和当前限制。

## 受众与主入口

- 主要受众：团队内部开发者。
- 主要入口：`erd/` 中的 EEG 校准与推理实现。
- `main.py` 的 FastAPI 服务不是本 README 的主入口；仅在项目结构或当前限制中说明。

## 内容结构

README 按以下顺序组织：

1. 项目定位与非临床用途声明。
2. 已实现的核心能力。
3. 原始 EEG 到预测结果的 Mermaid 数据流。
4. 主要目录及职责。
5. 已确认的运行环境与依赖边界。
6. 基于模拟 EEG 的快速开始。
7. `erd.enter.sim_demo` 统一入口说明。
8. 测试命令与当前测试状态。
9. Trace 相关文档索引。
10. 当前限制和模拟数据说明。

## 准确性边界

- 只描述源码中能够核实的能力，不承诺准确率、临床效果或生产就绪状态。
- 保留 EEG、ERD、ROI、Profile、Trace 等团队常用术语。
- 已确认的基础第三方依赖包括 NumPy、SciPy 和 pytest。
- `dao`、`db`、`schemes`、`impedance` 属于当前仓库外部依赖，不猜测其安装包名称。
- 不添加无法确认的许可证、版本徽章、发布包名称或性能指标。
- 详细 Trace 内容保留在现有 `docs/` 文档中，README 仅摘要并链接。

## 数据与安全说明

仓库内带有患者命名的 Profile、拓扑图和 Trace 样例均为模拟数据。README 必须明确说明这些内容不是真实患者数据，也不能用于临床诊断或医疗决策。

## 当前限制

- 项目尚无完整的依赖清单。
- 模拟 Trace 工具依赖仓库外部的 `impedance` 模块；当前环境会因该模块缺失而无法生成个人 Profile。
- 从父目录运行 `python -m pytest algo/tests` 时，pytest 收集到 18 个测试，但因外部 `dao` 模块缺失而在收集阶段中止。
- 根目录 `main.py` 依赖尚未完整接入，不作为推荐运行入口。
- 被 `.gitignore` 排除的嵌套 `algo/` 是旧代码副本，不在 README 的项目结构中介绍。

## 非目标

- 不修改算法、接口、依赖或测试。
- 不生成虚构的安装步骤。
- 不创建 Release、版本号或性能报告。
- 不把 README 扩展成完整算法论文或临床验证报告。

## 验收标准

- 根目录新增 `README.md`。
- README 为中文主文档，链接有效且使用相对路径。
- README 中的命令、路径、模块名可从当前仓库验证。
- 明确列出外部依赖、测试失败原因和模拟数据声明。
- Markdown 与 Mermaid 语法通过静态检查，且除 README 和本设计文档外无额外改动。
